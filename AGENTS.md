# Required startup reading

At the beginning of EVERY new chat in this repository, before running commands or taking action:

1. Read this `AGENTS.md` and the root `CLAUDE.md` in full. Check applicable parent and nested `AGENTS.md` instructions as well. If a file named `cluade.md` exists, read it too.
2. Read `docs/AGENT_WORKFLOW.md` before working with GitHub issues, including validation and closing requests.
3. Follow the documented workflow; do not treat a GitHub close alone as completion. Device-confirmed closes require swapping `validation` to `validated`, commenting and closing on GitHub, moving the row into its matching archive tier, and committing and pushing each issue separately.

Do not rely on memory or a previous chat having read these files. Direct user instructions take precedence.
